# 정산 계산 규칙

이 문서는 앱이 금액을 어떻게 나누는지에 대한 **기준 문서**다.
구현은 [src/index.html](../src/index.html) 의 `compute()` 와 `largestRemainder()` 에 들어 있고,
[tests/split.test.mjs](../tests/split.test.mjs) 가 이 문서의 규칙을 그대로 검증한다.
규칙을 바꾸려면 이 문서 → 테스트 → 구현 순서로 고친다.

## 용어

| 이름 | 뜻 |
|---|---|
| 항목 금액 | `단가 × 수량`, 원 단위 정수로 반올림 |
| 항목 합계 (`gross`) | 모든 항목 금액의 합 |
| 담은 금액 (`sub`) | 한 사람이 고른 메뉴에서 부담하게 된 금액 (소수 허용) |
| 미배분 (`orphan`) | 아무도 고르지 않은 메뉴의 금액 |
| 조정 (`adjustment`) | 할인(−) 또는 추가금(+) |
| 결제 총액 (`grand`) | `gross + 조정 합계`, 원 단위 정수로 반올림 |

## 1. 공동 메뉴는 고른 사람 수로 나눈다

한 항목을 고른 사람이 N명이면, 그 항목 금액을 **N으로 균등 분할**해 각자의 담은 금액에 더한다.
혼자 골랐으면 전액, 아무도 고르지 않았으면 미배분으로 간다.

```
담은 금액(사람) = Σ ( 항목 금액 / 그 항목을 고른 사람 수 )
```

수량이 2 이상이어도 마찬가지다. 2인분을 3명이 나눠 먹었으면 2인분 금액 전체를 3으로 나눈다.
"내가 1.5인분 먹었다" 같은 가중치는 지원하지 않는다 — 필요하면 항목을 쪼개서 입력한다.

## 2. 할인과 추가금은 담은 금액 비율대로 안분한다

조정의 금액은 다음과 같이 구한다.

- `mode: "amount"` → 입력한 금액
- `mode: "percent"` → `gross × 값 / 100`
- `kind: "discount"` 는 음수, `kind: "extra"` 는 양수. 입력값의 부호는 무시하고 절댓값을 쓴다.

조정 합계를 각 사람에게 **항목 합계에 대한 지분 비율**로 나눈다.
미배분도 하나의 몫으로 취급해 똑같이 할인·추가금을 나눠 받는다.

```
배분 전 금액(몫) = 담은 금액 + 조정 합계 × 담은 금액 / gross
```

이렇게 하면 미배분이 남아 있어도 `Σ 사람 + 미배분 = 결제 총액` 이 항상 성립한다.
`gross = 0` 이면 모두 0원이다.

**%는 항목 합계 기준이다.** 할인이 여러 개여도 서로 중첩 적용되지 않는다(비누적).
10% 할인 두 개는 19%가 아니라 20% 할인이다.

## 3. 1원 단위 나머지는 최대잉여법으로 배분한다

각 몫의 정확한 금액은 소수가 된다. 이를 정수 원으로 바꿀 때:

1. 모든 몫을 내림(`floor`)한다.
2. `결제 총액 − 내림 합계` 만큼의 원이 남는다.
3. 소수부가 큰 몫부터 1원씩 더해 남은 금액을 모두 소진한다.
4. 소수부가 **사실상 같으면**(차이 < 10⁻⁶) 참여자 목록 순서가 앞인 사람이 먼저 받는다.

4번이 중요하다. `10000 ÷ 3` 같은 경우 세 사람의 소수부가 이론상 동일한데,
부동소수점 오차에 따라 나머지 1원의 주인이 실행마다 달라질 수 있다.
오차 허용 비교로 동률을 깨서, **같은 입력이면 항상 같은 결과**가 나오게 한다.

결과: `10,000원 ÷ 3명 = 3,334 / 3,333 / 3,333`. 합은 정확히 10,000원이다.

내림 합계가 목표보다 크면(할인이 커서 총액이 음수로 갈 때 등) 반대로 소수부가 작은 쪽부터 1원씩 뺀다.

## 4. 영수증 인쇄 금액과의 대조

사용자가 영수증에 인쇄된 결제 금액을 입력하면 `계산 총액 − 인쇄 금액` 을 보여 준다.
0이 아니면 사진 인식이 틀렸거나 항목을 빠뜨린 것이다. 이 값은 계산에 영향을 주지 않는다 — 경고만 한다.

## 불변식

테스트가 지키는 성질. 어떤 입력에도 깨지면 안 된다.

1. `Σ 사람별 금액 + 미배분 금액 = 결제 총액` (정수, 오차 0)
2. 같은 입력 → 같은 출력 (나머지 1원의 주인까지)
3. 모든 사람별 금액은 정수
4. 한 사람의 금액은 정확한 몫에서 1원 이상 벗어나지 않는다
