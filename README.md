# 영수증 정산기

영수증 사진에서 메뉴와 가격을 자동으로 읽고, 여러 사람이 **동시에** 각자 먹은 메뉴를 고르면
공동 메뉴와 할인까지 반영해 1인당 정산 금액을 계산한다.

**배포된 앱** → https://claude.ai/code/artifact/3351faa1-33dc-49eb-890f-a755daa69c93

처음에는 나만 볼 수 있다. 같이 정산할 사람에게 열어 주려면 앱 화면의 공유 메뉴에서
**편집 가능(Contributor 이상)** 으로 초대한다. 보기 전용으로 초대된 사람은 금액은 볼 수 있지만
메뉴를 고르거나 항목을 고칠 수 없다.

## 동작

| 기능 | 설명 |
|---|---|
| 영수증 사진 인식 | 사진을 올리면 메뉴·단가·수량·할인·결제금액을 읽어 목록으로 만든다. 추가하기 전에 사람이 확인한다. |
| 실시간 공유 | 한 링크를 여러 명이 동시에 열고 각자 자기 메뉴를 고른다. 모든 변경이 바로 서로에게 보인다. |
| 내 이름 가져가기 | 참여자 칸에서 **내 이름**을 누르면, 그 사람의 메뉴만 큰 버튼으로 골라 담는 화면이 열린다. |
| 공동 메뉴 분할 | 한 메뉴를 여러 명이 고르면 금액을 고른 사람 수로 나눈다. |
| 할인·추가금 안분 | 쿠폰·통신사 할인·봉사료를 각자 담은 금액 비율대로 반영한다. |
| 1원 단위 보정 | 나머지 1원까지 나눠, 사람별 금액의 합이 결제 총액과 **정확히** 같다. |
| 총액 대조 | 영수증에 인쇄된 금액을 적어 두면 어긋날 때 알려 준다. (사진 인식 오류 잡기) |
| 결과 복사 | 카카오톡에 붙일 수 있는 텍스트로 복사한다. |

계산 규칙의 정확한 정의는 [docs/정산-규칙.md](docs/정산-규칙.md) 에 있다. **금액 로직을 건드리기 전에 반드시 읽는다.**

## 구조

```
영수증-정산기/
├── src/index.html          앱 전체 (단일 파일: 마크업 + CSS + JS)
├── tests/split.test.mjs    정산 계산 검증 — src 에서 함수를 직접 추출해 테스트한다
├── docs/정산-규칙.md        금액 분할·할인 안분·1원 보정 규칙의 기준 문서
└── README.md
```

`src/index.html` 은 `<!DOCTYPE>` / `<html>` / `<head>` / `<body>` 태그가 없다.
Artifact 로 배포될 때 플랫폼이 그 껍데기를 씌운다. 그래서 `<title>`, `<link>`, `<style>` 이 파일 맨 위에 바로 온다.
브라우저로 파일을 직접 열어도 렌더는 되지만, 공유 저장(`db`)과 사진 인식(`sample`)은 배포된 주소에서만 동작한다.

## 개발

```powershell
# 계산 로직 테스트 (의존성 없음, Node 18+)
node tests/split.test.mjs
```

고치고 나서 배포하려면 Claude Code 에서:

```
src/index.html 을 https://claude.ai/code/artifact/3351faa1-33dc-49eb-890f-a755daa69c93 에 다시 배포해 줘
```

같은 주소로 새 버전이 올라가고, 열려 있던 모든 화면이 새 버전으로 바뀐다.
**새 주소를 만들지 않도록 꼭 기존 URL을 함께 알려 준다.**

### 공유 데이터 구조

앱의 상태는 Artifact 의 `db` 에 들어간다. 모든 참여자가 같은 문서를 본다.

| 경로 | 내용 |
|---|---|
| `meta/session` | `{ title, receiptTotal }` |
| `items/{id}` | `{ name, unitPrice, qty, order }` |
| `people/{id}` | `{ name, order, ownerId, picks: { itemId: 1 } }` |
| `adjs/{id}` | `{ label, kind: discount\|extra, mode: amount\|percent, value, order }` |

**각자의 선택을 자기 문서에만 쓰는 게 핵심이다.** 메뉴 선택(`picks`)이 그 사람의 `people/{id}` 문서 안에 있어서,
여러 명이 동시에 자기 메뉴를 골라도 서로의 변경을 덮어쓰지 않는다.
이 구조를 깨고 선택을 한 문서에 모으면 동시 작업에서 데이터가 날아간다.

쓰기는 문서별 큐를 거친다(`enqueue`). 텍스트 입력은 420ms 디바운스 후에 저장한다.

### 함께 작업하기

```powershell
git switch -c 기능-이름
# ... 수정 ...
node tests/split.test.mjs
git add -A
git commit -m "설명"
```

원격 저장소를 아직 연결하지 않았다. GitHub 로 공유하려면:

```powershell
gh repo create 영수증-정산기 --private --source . --push
```

금액 계산을 바꿨다면 `tests/split.test.mjs` 에 그 경우를 추가한다.
테스트는 `src/index.html` 에서 함수를 문자열로 추출해 실행하므로, 함수 이름(`compute`, `largestRemainder`, `sorted`, `num`)을
바꾸면 테스트가 먼저 깨진다. 의도된 장치다.

## 아직 안 한 것
